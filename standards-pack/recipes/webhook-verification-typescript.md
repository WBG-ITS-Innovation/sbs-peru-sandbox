# TypeScript webhook verification — see the helper

The TypeScript webhook verification helper ships inside this pack at
`sdk-helpers/typescript/`. See its `README.md` for usage examples and
the verification surface. The helper uses only `node:crypto` from the
standard Node.js library and ships as dual ESM + CJS.

A reference snippet is not duplicated here because the helper IS
the reference — `index.ts` is ~150 lines and reads as documentation.
See `sdk-helpers/typescript/README.md` for the single-source-of-truth
usage examples.
